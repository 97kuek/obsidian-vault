## 1. 前半：生成モデルの復習

### 1.1 データ分布と確率モデル

- **データ分布 p_data(x)**：「顔画像生成器」のような仮想的な存在。手元のデータ集合 {x₁,…,x_N} はここから独立に生成されたと**仮定する**
    - 重要なのは「存在すると仮定しているだけ」で、形も中身も一切不明という点
- **確率モデル p_θ(x)**：我々が自分で用意する分布。構造もパラメータも把握・操作できる
- **確率モデル = モデルの構造 + パラメータ**
    - 構造：設計者が置く仮定（「ベルヌーイ分布に従う」など）
    - パラメータ θ：データから学習する部分。多いほどモデルの容量（capacity）が大きい
- **生成モデル**：p_θ(x) ≈ p_data(x) を達成した確率モデル。近似できていれば、そこからサンプリングすれば新しいデータが作れる

### 1.2 学習 = KL最小化 = 最尤推定（この等価性が肝）

- 本当は p_data とのKLを最小化したいが、p_data は手元にない
    
- そこで**経験分布** p̂ᴺ_data(x)（デルタ関数の平均 = 実データ点にだけ質量がある分布）で代用する
    
    θ̂ = argmin_θ D_KL[ p̂ᴺ_data(x) ‖ p_θ(x) ]
    
- KLを分解すると、
    
    D_KL = E_p̂[log p̂(x)] − E_p̂[log p_θ(x)]
    
    - 第1項は θ を含まない（経験分布のエントロピー） → **定数**
    - つまり最小化に効くのは第2項だけ
- 第2項をデルタ関数の性質 ∫δ(x−μ)f(x)dx = f(μ) を使って計算すると、単なる**データ点での対数尤度の平均**になる
    
    θ̂ = argmax_θ Σᵢ log p_θ(xᵢ)
    
- 一方、尤度関数 f_x(θ) ≡ p_θ(x) を「θ の関数」と見たときの最尤推定も、独立性から積 → 対数を取って和になり、**まったく同じ式**になる
    
- **結論：KLダイバージェンス最小化 ⇔ 最尤推定**。同じことを2つの視点で言っているだけ
    

### 1.3 ただし限界がある

- p_θ(x) が単純（単一のガウス分布など）なら、微分して0と置けば θ̂ が閉形式で求まる
- しかし **混合モデルやニューラルネットの場合、解析的に解けない**
- → ここから今回の本題

## 2. 潜在変数モデルと混合モデル

### 2.1 コインの例（直感）

- 従来：コイン1枚を N 回投げる → 単純なベルヌーイ分布
- 今回の仮定：**コインが K 枚ある**
    - 毎回、K枚のうち1枚が選ばれて投げられる
    - コインごとに表の出やすさ μ_k が違う
- **観測できるのは「表・表・裏…」という結果だけ**。どの試行がどのコインだったかは分からない
- しかも「K枚ある」という仮定自体、妥当かどうかは仮定を置いた時点では検証不能

この「観測できないが、データの背後で結果を左右している要因」が潜在変数です。

### 2.2 用語の整理

- **潜在変数 z**：観測されない確率変数。ここでは「どのコインか」を表す one-hot ベクトル z = [z₁,…,z_K]ᵀ ∈ {0,1}ᴷ, Σₖ zₖ = 1
    - z = [1,0,…,0] なら1番目のコイン
- **観測変数 x**：実際にデータとして観測される確率変数（表/裏）
- **潜在変数モデル**：z を含めた生成モデル全体

### 2.3 生成過程を定式化する

潜在変数モデルは「生成過程（generative process）」を書き下すと理解しやすいです。各 i = 1,…,N について：

1. **どのコインを選ぶか**を事前分布からサンプリング
    
    zᵢ ~ p_π(z) = Cat(z; π) = ∏ₖ πₖ^{zₖ}
    
    - **カテゴリ分布**。πₖ は k番目が選ばれる確率（Σπₖ = 1）
    - 直感：**いびつな多面サイコロを振ってコインを選ぶ**。いびつさを表すのが π
2. **選んだコインを投げる**
    
    xᵢ ~ p_μ(x | z = zᵢ) = Bern(x; μ_k) = μ_k^x (1−μ_k)^{1−x}
    
    - スライドでは ∏ₖ {μₖ^x(1−μₖ)^{1−x}}^{zₖ} と書かれていますが、これは one-hot の zₖ が指数に乗ることで「選ばれた k の項だけが残る」というトリック
    - ポイントは、これが**条件付き分布** p(x|z) になっていること

### 2.4 同時分布 → 周辺化 → 混合モデル

- **同時分布**：p(x, z) = p(x|z)p(z) = ∏ₖ {πₖ μₖ^x (1−μₖ)^{1−x}}^{zₖ}
    
- z は観測できないので、**z について総和を取って消す（周辺化）**
    
    p(x) = Σ_z p(x,z) = Σₖ πₖ μₖ^x (1−μₖ)^{1−x}
    
- 結果は**ベルヌーイ分布の線形和** → これが**混合ベルヌーイモデル**
    
    - 一般に、確率分布の線形和で表されるモデルを**混合モデル（mixture model）**という
    - πₖ は各成分の**混合係数（重み）**
- 「潜在変数を周辺化すると混合モデルになる」という対応関係が、この節の中心的なメッセージです
    

### 2.5 グラフィカルモデル

- 確率変数間の依存関係（条件付き独立性）を図で表したもの
- 表記ルール
    - 白丸 = 潜在変数、灰色丸 = 観測変数（観測済みは塗る）
    - 矢印 = 依存の向き（z → x）
    - 黒点 = パラメータ（π, μ）
    - 四角い枠 = **プレート**。「これを N 回繰り返す」の意味
- 意味：**潜在変数は観測変数の「要因」として仮定されている**

### 2.6 何が問題なのか

最尤推定したい対数周辺尤度は、

log p(X) = Σᵢ log ( Σₖ πₖ μₖ^{xᵢ}(1−μₖ)^{1−xᵢ} )

- **log の中に Σ が入っている**のが致命的
- 単一分布なら log が積をバラして扱いやすい和になったのに、混合だとそれができない
- μₖ と πₖ で微分して0と置いても、互いに絡み合って解けない
- → 別の解法（EM）が必要

## 3. EMアルゴリズム

### 3.1 一般化した設定

- 潜在変数 z を1つ含む生成モデル：log p_θ(x) = log Σ_z p_θ(x, z)
    - z は離散で説明しているが、連続なら Σ が ∫ になるだけ
- **前提**：同時分布 p_θ(x,z) と事後分布 p_θ(z|x) は計算が容易とする
    - この前提が崩れるとEMは使えない（後述。そしてVAEはまさにここを突破する話）

### 3.2 ELBOの導出（式変形の追い方）

潜在変数 z 上の**任意の分布 q(z)** を持ち込みます。ここが天才的な一手。

1. log p_θ(x) に Σ_z q(z) = 1 を掛ける（何も変えていない）
    
    log p_θ(x) = log p_θ(x) · Σ_z q(z) = Σ_z q(z) log p_θ(x)
    
2. ベイズの定理 p_θ(x) = p_θ(x,z) / p_θ(z|x) を使い、さらに q(z) で分母分子を掛ける
    
3. 対数を2つに分解すると：
    
    **log p_θ(x) = L(q, θ; x) + D_KL[ q(z) ‖ p_θ(z|x) ]**
    
    ただし L(q,θ;x) ≡ Σ_z q(z) log { p_θ(x,z) / q(z) }
    

### 3.3 ELBO の意味

- 第1項 L(q,θ;x) を**エビデンス下界（ELBO: evidence lower bound）**と呼ぶ
    - 「エビデンス」＝周辺尤度 p_θ(x) の別名
- 第2項のKLは**必ず0以上** → **log p_θ(x) ≥ L(q,θ;x)** が常に成立
    - だから「下界」
- 決定的に嬉しい点：**ELBOでは log が和の中に入っている**（log{p(x,z)/q(z)} の形）
    - さっき困っていた「log Σ」が解消されている
- イェンセンの不等式を使えばもっと手早く導出できる（補足スライド）。log は上に凸なので不等号が反転し、そのギャップがちょうど KL[q‖p(z|x)] に対応する
- → **扱いにくい周辺尤度の代わりに、ELBOを最大化すればよい**

### 3.4 E ステップと M ステップ

式を書き換えると L(q,θ;x) = log p_θ(x) − D_KL[q(z)‖p_θ(z|x)]。これを **q と θ で交互に最大化**します。

**1. q についての最大化（Eステップ）**

- θ を固定すると log p_θ(x) は定数
- ELBOが最大になるのは第2項のKLが0のとき
- KL=0 ⇔ **q(z) = p_θ(z|x)**、すなわち**潜在変数の事後分布**を計算すればよい
- このとき下界は真の対数尤度と**ピッタリ一致する**（バウンドがタイトになる）

**2. θ についての最大化（Mステップ）**

- q を固定して L(q,θ) を θ について最大化
    
- q(z) = p_{θ_old}(z|x) を代入して展開すると
    
    L = Σ_z p_{θ_old}(z|x) log p_θ(x,z) − Σ_z p_{θ_old}(z|x) log p_{θ_old}(z|x)
    
- 第2項は θ_old だけの関数 → **θ に無関係な定数**
    
- したがってMステップで実際に最大化するのは第1項だけ：
    
    **E_{p_{θ_old}(z|x)}[ log p_θ(x, z) ]**（同時分布の対数尤度の期待値）
    
- 名前の由来：Eステップで**E**xpectation（期待値の準備＝事後分布計算）、Mステップで**M**aximization
    

### 3.5 アルゴリズムの流れ

1. パラメータ θ をランダムに初期化
2. 現在の θ の下で事後分布 p_θ(z|x) = p_θ(x,z) / Σ_z p_θ(x,z) を計算（**Eステップ**）
3. q(z) = p_{θ_old}(z|x) として、ELBOを最大化する θ を求めて更新（**Mステップ**）
4. 収束するまで 2, 3 を繰り返す

### 3.6 なぜ単調増加するのか（図の読み方）

スライド34の図（青＝ELBO、赤＝対数尤度）が理解の要です。

- **Eステップ**：θ_old の点で、青い下界曲線が赤い曲線に**接する**ように q を選ぶ（KL=0）
- **Mステップ**：接している青い曲線を最大化して θ_new に移る
- 青が上がった分、赤（真の対数尤度）は**それ以上に上がる**（赤 ≥ 青、かつ θ_old では等号だったため）
- → 反復のたびに log p_θ(x) が**単調増加することが保証される**

### 3.7 特徴と限界

- **保証されること**：対数尤度の単調増加、局所最適解への収束
- **保証されないこと**：大域最適解への収束。**初期値依存**（実務では複数初期値で回す／k-meansで初期化するのが定石）
- **使えない場合**：事後分布 p_θ(z|x) の計算が困難なとき（Eステップが実行不能）
    - ニューラルネットで p(x|z) を表現するとまさにこれが起きる
    - → 事後分布を近似する q を別のネットワークで用意する＝**VAEの推論モデル**。第3回への直接の橋渡しです

## 4. 混合モデルにおける具体的なEM

### 4.1 Eステップ：負担率

混合ベルヌーイモデルの事後分布を計算すると、

γ(zₖ) ≡ p(zₖ = 1 | x) = πₖ μₖ^x(1−μₖ)^{1−x} / Σⱼ πⱼ μⱼ^x(1−μⱼ)^{1−x}

- これを**負担率（responsibility）**と呼ぶ
- 意味：「点 x の確率密度のうち、**k番目の成分がどれだけ寄与しているか**の割合」
- 分母はただの正規化（Σₖ γ(zₖ) = 1）
- 直感：「このデータは、どのコインから出たものらしいか」の**ソフトな割り当て**
    - k-meansのハードな割り当て（0か1か）を、確率的に緩めたものと見ると分かりやすい

### 4.2 Mステップ：更新式の導出

同時分布の対数尤度は（one-hot性のおかげで）きれいに和の形になります：

log p(x,z) = Σₖ zₖ { log πₖ + x log μₖ + (1−x) log(1−μₖ) }

これの事後分布による期待値を取ると、E[zₖ] = p(zₖ=1|x) = γ(zₖ) なので、**zₖ が負担率に置き換わる**だけ。データ集合全体では：

Σᵢ Σₖ γ(z_ik){ log πₖ + xᵢ log μₖ + (1−xᵢ) log(1−μₖ) }

**μₖ について**

- 偏微分して0と置くだけ（制約なし）
    
    μ̂ₖ = (1/Nₖ) Σᵢ γ(z_ik) xᵢ, ただし Nₖ = Σᵢ γ(z_ik)
    
- 意味：**負担率で重み付けした x の平均**。Nₖ は「成分 k が実質的に担当しているデータ数」
    

**πₖ について**

- Σₖ πₖ = 1 という制約があるので、**ラグランジュの未定乗数法**を使う
    
- 目的関数に λ(Σₖ πₖ − 1) を足して πₖ で偏微分 → (1/πₖ)Σᵢγ(z_ik) + λ = 0
    
- 両辺に πₖ を掛けて k について総和 → Σₖγ = 1 より N = −λ Σₖ πₖ、制約から **N = −λ**
    
- 代入して
    
    π̂ₖ = Nₖ / N
    
- 意味：**成分 k が担当したデータの割合**。極めて自然な結果
    

### 4.3 まとめると（混合ベルヌーイのEM）

1. μₖ, πₖ をランダムに初期化
2. 負担率 γ(z_ik) を計算（Eステップ）
3. μ̂ₖ = (1/Nₖ)Σᵢγ(z_ik)xᵢ、π̂ₖ = Nₖ/N で更新（Mステップ）
4. 収束まで反復

得られるもの：**モデルのパラメータ**と、**データごとの負担率（＝どのコインか）**の両方。後者があるのでクラスタリングに使えます。

### 4.4 多次元入力への拡張（MNIST）

- コインの例では x はスカラーの2値だったが、x = [x₁,…,x_D]ᵀ ∈ {0,1}ᴰ に拡張
- 各次元がパラメータ μₖ = [μ_k1,…,μ_kD]ᵀ の下で**独立**と仮定：p(x) = ∏_d Bern(x_d; μ_kd)
    - （画素間の相関を無視する強い仮定。ここが後の「単純な分布では高次元の複雑な依存関係を扱えない」という話につながる）
- MNIST（28×28=784次元、[0,1]正規化して閾値で2値化）に適用
- 数式の形はほぼ同じで、スカラー x がベクトル x になるだけ
- 結果：0, 5, 7 の画像で K=3 で学習すると、各クラスタの μₖ が**それぞれの数字のぼやけた平均画像**になる。π は [0.42, 0.27, 0.31] 程度
- テストデータの負担率がほぼ [0,0,1] のように一つに立つ → うまくクラスタリングできている
- ここで μₖ が「クラスタの代表画像」として直接見える、というのが潜在変数モデルの解釈性の良さです

### 4.5 混合ガウスモデル（GMM）

- 実数値データを扱いたいときは、ベルヌーイを多次元ガウス N(x; μₖ, Σₖ) に差し替えるだけ
    
- 周辺分布：p(x) = Σₖ πₖ N(x; μₖ, Σₖ)
    
- EMの流れも完全に同じ構造で、負担率が γ(z_ik) = πₖN(x;μₖ,Σₖ) / Σⱼ πⱼN(x;μⱼ,Σⱼ) になり、更新式は
    
    - μ̂ₖ = (1/Nₖ) Σᵢ γ(z_ik) xᵢ （重み付き平均）
    - Σ̂ₖ = (1/Nₖ) Σᵢ γ(z_ik)(xᵢ−μ̂ₖ)(xᵢ−μ̂ₖ)ᵀ （重み付き共分散）
    - π̂ₖ = Nₖ / N
- 2次元データに K=3 で当てはめると、3つのガウス分布がデータの塊に割り当てられる（＝クラスタリング）
    
- 「興味のある方は導出してみてください」とありますが、混合ベルヌーイと**まったく同じ手順**（Mステップの目的関数を μ, Σ, π で偏微分、π だけラグランジュ）で出ます。手を動かす価値はあります

## 5. 一般の生成モデルへ

### 5.1 設計手順

複数の潜在変数・観測変数を置けば、より複雑なモデルが作れます。手順は定型：

1. 確率変数・潜在変数を置き、それぞれの確率分布を仮定する（グラフィカルモデルを描くと整理しやすい）
2. すべての変数の**同時分布**を求める（条件付き分布の積）
    - 例：p(x,y,z,a,b) = p(x|y,z)p(y|a,b)p(z|b)p(a)p(b)
3. 潜在変数について**周辺化**して、観測変数の周辺尤度 p(x) を得る（離散なら総和、連続なら積分）
4. 周辺尤度を最大化する（学習）

### 5.2 推論（inference）

- **定義**：観測変数が与えられた下で、潜在変数の分布 p(z|x) を求めること
- **「結果」から「原因」を探る作業**。潜在変数モデルにおける中核概念
- MNISTの例では「画像 x からクラスタ z の負担率を求める」がまさに推論
- グラフィカルモデルでは**点線の矢印**（x → z）で描くことが多い
- 混合モデルでは解析的に計算できたが、**一般には計算困難**
    - だから様々な推論手法（変分推論、MCMC、そしてVAEの償却推論）が提案されている

### 5.3 従来の生成モデルの課題

- ここまでのモデルは、**複雑な観測データを直接生成することを意図していなかった**
    - 単純な確率分布では、次元間に複雑な依存関係を持つ高次元入力を直接扱えないため（4.4の「各画素独立」仮定を思い出す）
- 扱うデータは前処理され、**分析のため**に使われていた
- 例：トピックモデル（LDA）
    - 文書の生成過程をモデル化し、文書のトピックを**推論**できる
    - しかし文書そのものを生成する意図はない

### 5.4 深層生成モデルへ

- DNNで確率分布を表現するようになった → **深層生成モデル**
- 変わった点
    - より複雑な入力を扱える
    - 画像のような複雑なデータを直接生成できる
    - **誤差逆伝播法で勾配を求めて学習する**（従来のEMのような閉形式更新ではない）
- 表現の仕方は4通りに整理される（表のまとめ）

|p_θ(x\|z)（zを入力、xを出力するDNN）|VAE / GAN / フロー / 拡散|VAEは下界のみ、GANは不可、フローは可能|低〜高|VAEは推論モデル、フローは逆変換|

## 6. 全体のまとめ（1本の線で）

- 生成モデルの学習 = KL最小化 = 最尤推定
- **潜在変数**を導入すると、観測データに現れない「要因」を仮定できる
- 潜在変数を周辺化すると **混合モデル**（確率分布の線形和）になる
- 混合モデルの対数周辺尤度は log の中に和があり**解析的に解けない**
- 任意分布 q を導入すると log p(x) = **ELBO** + KL[q‖p(z|x)] と分解できる
- ELBOを q（Eステップ）と θ（Mステップ）で交互最大化するのが **EMアルゴリズム**
- 混合モデルではEステップが**負担率**の計算、Mステップが**負担率で重み付けした平均**になる
- ただしEMは事後分布が計算できることが前提。一般には**推論が計算困難**
- 従来モデルは複雑なデータの直接生成を意図していなかったが、**深層生成モデル**はDNNの表現力でそれを可能にした

## 7. 補足：あなたの研究との接点

音声系だと、この回の内容は思っている以上に地続きです。

- GMMは音声認識のGMM-HMM時代の中核であり、話者モデリングのUBM/i-vectorもGMMベース
- 音源分離では、時間周波数マスク推定を**複素ガウス混合モデルのEM**で解く定式化（CGMM、MNMF、空間クラスタリング系）が古典的な主流手法。マイク間位相差を潜在変数付きモデルで扱い、EMでマスクを求める流れは、まさに今回の「負担率＝ソフトマスク」の構図そのものです
- あなたが扱っている2ch TF-Locoformerのようなニューラル手法は「マスクをEMで推定する」代わりに「マスクを直接回帰する」路線ですが、両者の対比を理解しておくと、なぜ空間情報が効くのか／なぜ教師なし適応（RemixIT）が成立しうるのかの説明が一段深くなります
- また、RemixITのような擬似ラベル反復学習は、構造としてEMと同型（教師モデルで潜在的な正解を推定 → 生徒モデルのパラメータを更新 → 反復）です。「なぜ peak then degradation が起きるか」を、EMの局所最適・初期値依存・自己確認バイアスの観点から議論すると、考察の筋が通しやすいかもしれません

演習（混合ベルヌーイ・混合ガウスのパラメータ推定）は、負担率の計算と重み付き平均の更新をNumPyで20〜30行書くだけなので、手を動かすとELBOの単調増加も実際にプロットで確認できます。log-sum-expで数値安定化するのを忘れずに。
