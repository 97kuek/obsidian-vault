
## Terms

### ドメイン内

実際にモデルを使う環境と同じ分布から来ている

### 対データ

入力の混合信号とその正解であるクリーン音声のペアのこと

### in-the-wildな混合信号

実環境でそのまま録れたノイズ入り音声のこと
いくらでも大量に集められるが、正解がついていない

### バッチサイズ

学習データ全体を一度にモデルへ流すのは計算資源的に不可能なので、数サンプルずつの小さな塊に区切って処理する

### 混合一貫性射影層

**やっていること**

- 分離モデルが音声とノイズを出力しても、そのままでは足しても元の混合に戻らない

$$\hat{s} + \hat{n} \neq x$$

- そこで、残差を出力に配分し直して、**必ず $\hat{s} + \hat{n} = x$ になるよう補正する**のが混合一貫性射影層
- 学習パラメータはなく、単なる後処理
- 音声強調（$M=2$）なら、実質「音声を推定したら、ノイズは $\hat{n} = x - \hat{s}$ と決め打ちする」のと同じこと

**RemixITでなぜ必要か**

- 式(5)で $\tilde{m} = \tilde{s} + P\tilde{n}$ という偽の混合を作るから。
- $\tilde{s} + \tilde{n} = m$ が保証されていないと、組み替えて作った混合が本物の混合とエネルギー的にズレてしまい、生徒が現実とは違う分布を学んでしまう
- **再混合という操作が成り立つための土台**

## Abstract

- 本論文は **RemixIT** という、単一の分離されたドメイン内クリーン音声波形もノイズ波形も一切必要とせずに音声強調モデルを学習できる、シンプルかつ効果的な自己教師あり手法を提案する
- 従来手法はドメイン内のクリーンな目標信号に依存しており、学習サンプルとテストサンプルの間にドメインミスマッチがあると性能が劣化するという制約を抱えていた
- RemixIT はこの制約を克服する

手法の骨子は**継続的自己学習** スキームである:

1. ドメイン外 (OOD) データで事前学習された**教師モデル**が、ドメイン内の混合信号に対して疑似目標信号を推定する
2. 推定されたクリーン音声とノイズを**置換 (permute) して再混合**することで、新しいブートストラップ混合信号とそれに対応する疑似目標のセットを生成する
3. これを用いて**生徒ネットワーク**を学習させる
4. 逆に教師は、最新の生徒モデルのパラメータを用いて周期的に自身の推定を洗練させる

- 複数の音声強調データセット・タスクでの実験により、従来手法に対する優位性が示されただけでなく、RemixIT が**任意の分離モデルと組み合わせ可能**であり、**あらゆる半教師あり／教師なしドメイン適応タスクに適用可能**であることが示された
- 理論解析と実証的証拠により、生徒モデルが著しく劣化した疑似目標を観測しながらもなお性能を向上させ続けるという、自己学習スキームの内部機構が明らかにされる

## I. Introduction

- 音声処理における最も基本的な問題の一つが**音声強調**
- その目標はノイズを含む入力録音からクリーンな音声成分を分離・再構成すること
- こうした雑音除去モデルをフロントエンドとして用いることが、ASRや話者認識システムの構築に有用であることが複数の研究で示されている
- ニューラルネットワークの汎用性は音声強調を含む様々な信号処理問題で有益であることが証明されており、畳み込みネットワーク、再帰的処理、自己注意機構、敵対的生成ネットワーク (GAN)、変分オートエンコーダなど洗練されたアーキテクチャが提案されてきた

> しかしこれらは**ドメイン内の対データが大量にある場合**に有効であり、実世界応用では in-the-wild な混合信号で学習できる頑健なアルゴリズムの開発が必要とされる

### 用語の整理

- **自己教師あり学習 (SSL) / 教師なし手法**: 半教師あり手法と異なり、クリーンな目標信号にアクセスできない
- **自己学習 (self-training)**: 上記とは直交する概念で、以前に学習されたモデル (教師) が提供する疑似目標に基づいて新しいモデル (生徒) を学習するアルゴリズムを指す

この統一的な用語体系のもとでは、RemixIT は教師モデルの事前学習に教師なしデータのみを使う場合、**教師なし自己学習アルゴリズム**とみなすことができる。

### 関連研究

- 実世界設定では音声録音が加法性ノイズで劣化するため、頑健な埋め込みの自己学習は特に困難であり、入力ノイズ分布への適応が要求される
- 教師なし音声除去の既存アプローチには以下がある
	- ノイズ混合音声中の比較的クリーンな区間を同定して学習する手法
	- ASR 損失を利用する手法
	- 視覚的手がかりを利用する手法
	- マイクロホンアレイによる音源の空間的分離性を利用する手法
- **MixIT** は、実世界の単一チャネル録音のみを用いて、混合信号のさらなる混合 を人工的に生成し独立音源を推定することで、分離モデルの教師なし学習を可能にする。MixIT は様々な音声強調タスクで成功しているが、**ドメイン内ノイズサンプルへのアクセスを仮定する**ため汎用性に制約がある。この制約を克服するために追加の OOD ノイズ音源を注入する手法もあるが、入力 SNR 分布が変わってしまい、注入ノイズと実ノイズの分布シフトに性能が大きく依存する。

一方、自己学習の戦略としては、ラベルありデータとラベルなしデータの凸結合を用いる手法 (Mixup など) が分類タスクで有望な結果を示し、音声タスクにも適用されてきた。事前学習済み MixIT モデルの出力の部分集合を用いて、推定音源数の少ない生徒モデルを学習させ入力 SNR 分布のミスマッチを解決する研究や、教師の推定波形を目標として生徒がテスト時適応を行う研究もある。しかしこれらは**凍結された教師の疑似目標に対する生徒予測の一貫性のみを強制する**ものである。

本研究に最も近いのは歌声分離のための教師–生徒フレームワークである。この手法は教師ありの OOD データで教師を事前学習し、ドメイン内のノイズ混合データセットに推論を行って新しい疑似ラベル付きデータセットを保存する。第2段階で、事前定義された信頼度品質閾値を超えたスコアの推定音源をランダムに混合して生徒を学習させる。しかし、**教師の推定 SNR が低い場合や閾値の選択が適切でない場合、生徒モデルも性能が低くなってしまう**。

対照的に、最も成功している自己学習アプローチは、指数移動平均スキームによって教師の重みを反復的に更新するか、より表現力の高いノイジーな生徒の重みで教師を逐次的に更新することを提案している。

### 本研究の貢献

RemixIT は、疑似ラベリングと継続的学習に関する上記の SOTA な SSL 戦略に基づきつつ、OOD データで音声強調モデルを学習させる新しい技術を提供する。教師の推定を置換・再混合して生成した自己拡張混合信号を用いて生徒モデルを学習し、それらを通常の回帰の疑似目標として用いる。さらに RemixIT は自己学習を**生涯学習プロセス**として扱い、生徒の重みを用いて教師モデルを継続的に更新することで、より速く頑健な収束につながる。

RemixIT は以下を実現する初の手法である

- ドメイン内混合データセットと OOD ノイズ音源のみを用いた自己教師あり学習の実行 (例: OOD データセットでの MixIT 事前学習済み教師)
- クリーン音声波形やアドホックなフィルタリング手順を必要とせず、複数の教師なし・半教師あり雑音除去タスクで SOTA な結果を達成
- 様々なノイズレベル下でなぜ機能するかについての強い理論的・実証的根拠
- 膨大な量の教師なしデータを活用し、多様な学習・適応シナリオで汎化する能力

## II. RemixIT の手法

- RemixIT は、ノイズ観測からクリーン音声信号を分離するように音声強調モデルを学習させる
- 一般に、時間領域サンプル数 $T$ の各入力ノイズ音声録音に対して $M$ 個の音源波形を出力する分離モデル $f$ を学習する
- バッチサイズ $B$ の入力波形 $\mathbf{x} \in \mathbb{R}^{B \times T}$ が与えられたとき、ネットワークはすべての音源を推定する

$$\hat{\mathbf{s}}, \hat{\mathbf{n}} = f(\mathbf{x}; \theta), \quad \mathbf{x} = \mathbf{s} + \sum_{i=1}^{M-1} [\mathbf{n}]_i = \hat{\mathbf{s}} + \sum_{i=1}^{M-1} [\hat{\mathbf{n}}]_i \tag{1}$$

- ここで $\hat{\mathbf{s}}, \mathbf{s} \in \mathbb{R}^{B \times T}$、$\hat{\mathbf{n}}, \mathbf{n} \in \mathbb{R}^{(M-1) \times B \times T}$、$\theta$ はそれぞれ推定音声信号、クリーン音声目標、推定ノイズ信号、ノイズ目標、モデルパラメータである
- 推定音源 $\hat{\mathbf{s}}$ と $\hat{\mathbf{n}}$ が初期入力混合 $\mathbf{x}$ に加算的に一致するよう、**混合一貫性射影層** を用いて強制する。

### Algorithm 1: ノイズ混合データセット $\mathcal{D}_m$ に対する RemixIT

```
θ_T^(0) ← PRETRAIN_TEACHER(f_T, D_0)
θ_S    ← INITIALIZE_STUDENT(f_S)

for k = 0; k++; while k <= K do
    for SAMPLE BATCH m ∈ D_m, m ∈ R^(B×T) do
        s̃, ñ    ← f_T(m; θ_T^(k))          // 教師の推定
        m̃       = s̃ + P·ñ                  // ブートストラップ再混合
        ŝ, n̂    ← f_S(m̃; θ_S^(k))          // 生徒の推定
        L_RemixIT = Σ_b [ L(ŝ_b, s̃_b) + L(n̂_b, [P·ñ]_b) ]
        θ_S     ← UPDATE_STUDENT(θ_S, ∇_θS L_RemixIT)
    end
    θ_T^(k+1) ← UPDATE_TEACHER(θ_T^(k), θ_S)
end
```

### A. 教師あり学習 (比較対象)

教師あり学習は音声強調モデルの学習における最も直接的な方法であり、ドメイン内のクリーン音声録音 $\mathbf{s} \sim \mathcal{D}_s$ とノイズ音源 $\mathbf{n} \sim \mathcal{D}_n$ の両方へのアクセスを仮定する。各学習ステップで合成混合 $\mathbf{m} = \mathbf{s} + \mathbf{n}$ を生成し、モデルは各入力に対して $M = 2$ 音源を予測し、以下の損失を最小化する:

$$\mathcal{L}_{\text{Supervised}} = \sum_{b=1}^{B} \left[ \mathcal{L}(\hat{\mathbf{s}}_b, \mathbf{s}_b) + \mathcal{L}(\hat{\mathbf{n}}_b, \mathbf{n}_b) \right] \tag{2}$$

$\mathcal{L}$ は推定と対応する目標の再構成誤差にペナルティを与える任意の信号レベル損失関数である。しかしこの学習プロセスは、実世界の混合分布を捉えるためのクリーン音声とノイズ音源の可用性に完全に依存しており、未知のテスト条件下で性能低下に対して脆弱である。

### B. Mixture Invariant Training (MixIT)

MixIT は、人工的な**混合の混合 (MoMs)** を用いて分離モデルを学習するシンプルかつ効果的なアイデアである。MixIT は学習時に2種類のデータソースを仮定する: 音声とノイズ音源の混合からなる $\mathcal{D}_m$ と、単一のノイズ源からのノイズ録音を含む $\mathcal{D}'_n$。

学習は、ノイズ音声録音のバッチ $\mathbf{m} \sim \mathcal{D}_m$ (ここで $\mathbf{m} = \mathbf{s} + \mathbf{n}^{(1)}$) をサンプリングし、別の分離ノイズ録音のバッチ $\mathbf{n}^{(2)} \sim \mathcal{D}'_n$ と混合することに帰着する。**注意すべきは、実世界の真のノイズ分布 $\mathcal{D}^__n$ ($\mathbf{n}^{(1)} \sim \mathcal{D}^__n$) は未知であり、利用可能な $\mathcal{D}'_n$ と必ずしも同じではない**という点である。

分離モデル $f_M$ は合成入力 MoM バッチ $\mathbf{x} = \mathbf{s} + \mathbf{n}_1 + \mathbf{n}_2$ で学習され、$M = 3$ 音源 $\hat{\mathbf{s}}, \hat{\mathbf{n}}^{(1)}, \hat{\mathbf{n}}^{(2)} = f_M(\mathbf{x}; \theta_M)$ の再構成を試み、以下の置換不変損失を最小化する:

$$\mathcal{L}^{(b)}_{\text{MixIT}} = \min_{\pi \in \mathcal{P}} \left[ \mathcal{L}(\hat{\mathbf{s}}_b + \hat{\mathbf{n}}^{(\pi_1)}_b, \mathbf{m}_b) + \mathcal{L}(\hat{\mathbf{n}}^{(\pi_2)}_b, \mathbf{n}_b) \right] \tag{3}$$

ここで $b$ はバッチインデックス、$\mathcal{P} := {(1,2),(2,1)}$ はモデルのノイズ出力スロット間の置換集合である。複雑な置換不変ランドスケープの問題を回避するため、ノイズ推定の確率的割り当てを用いることもできる。

ノイズ音源が互いにおよびクリーン音声成分と独立ならば、モデルは第1推定スロットと2つのノイズスロットのいずれかを用いて混合を再構成することでこの損失を最小化できる。しかし、**真の背景ノイズ分布 $\mathcal{D}^*_n$ を適切に捉える多様なドメイン内ノイズ録音集合 $\mathcal{D}'_n$ にアクセスできるという仮定**が、多くの実世界設定で非現実的である。

### C. RemixIT: ブートストラップ再混合による自己学習

上記2つの学習手続きがドメイン内のグラウンドトゥルース信号を必要とするのに対し、RemixIT は**混合データセット $\mathcal{D}_m$ 以外のドメイン内情報に一切依存しない**。

本手法は教師–生徒フレームワークを用い、教師のノイズ推定をミニバッチ内でランダムに置換し、教師の音声推定と再混合してブートストラップ混合を作る。生徒モデルはブートストラップ混合を入力とし、教師の疑似目標信号に対して通常の教師あり損失で回帰することで学習される。さらに RemixIT は、数回の最適化ステップの後に生徒モデルの重みを用いて教師ネットワークを更新するという、ノイジーな疑似目標信号の**継続的洗練**を享受する。

#### 1) 教師–生徒フレームワーク

初期教師モデルとして、RemixIT は OOD データセット $\mathcal{D}_0$ で事前学習された任意の音声強調モデル (音声成分と1つ以上のノイズ推定波形を出力するもの) を使用できる。これにより:

- 教師が**教師あり損失**で学習された場合 → RemixIT は**半教師ありドメイン適応**として具現化
- 教師が **MixIT** で学習された場合 → **SSL 学習スキーム**として具現化

ドメイン内ノイズ混合バッチ $\mathbf{m} = \mathbf{s} + \mathbf{n} \in \mathbb{R}^{B \times T}$, $\mathbf{m} \sim \mathcal{D}_m$ に対し、教師モデルは音声成分とノイズ成分を推定する:

$$\tilde{\mathbf{s}}, \tilde{\mathbf{n}} = f_T(\mathbf{x}; \theta^{(k)}_T), \quad \mathbf{m} = \tilde{\mathbf{s}} + \sum_{i=1}^{M-1} [\mathbf{n}']_i \tag{4}$$

ここで $\theta^{(k)}_T$ は $k$ 番目の最適化ステップにおける教師モデルのパラメータである。第2式は混合一貫性を強制しているため成立する。MixIT 事前学習モデルは $M = 3$ 音源を推定するが、後半2つのノイズ推定波形を加算することで統合ノイズ推定 $\tilde{\mathbf{n}} = \sum_{i=1}^{M-1}[\mathbf{n}']_i$ を容易に得られる。

サイズ $B$ のバッチ内の教師の推定は、推定音声とノイズ音源をランダムな順序で再混合してブートストラップ混合 $\tilde{\mathbf{m}}$ を生成するために使われる:

$$\tilde{\mathbf{m}} = \tilde{\mathbf{s}} + \tilde{\mathbf{n}}^{(P)} \in \mathbb{R}^{B \times T}, \quad \tilde{\mathbf{n}}^{(P)} = P\tilde{\mathbf{n}}, \quad P \sim \Pi_{B \times B} \tag{5}$$

$P$ はすべての $B \times B$ 置換行列の集合から一様に抽出され、置換ノイズ源 $\tilde{\mathbf{n}}^{(P)}$ を生成する。元の教師の音声推定 $\tilde{\mathbf{s}}$ と置換ノイズ源 $\tilde{\mathbf{n}}^{(P)}$ が、新たに生成されたブートストラップ混合バッチ $\tilde{\mathbf{m}}$ 上で生徒モデル $f_S$ を学習する目標ペアとして使われる:

$$\hat{\mathbf{s}}, \hat{\mathbf{n}} = f_S(\tilde{\mathbf{m}}; \theta^{(k)}_S), \quad \hat{\mathbf{s}}, \hat{\mathbf{n}} \in \mathbb{R}^{B \times T}$$ $$\mathcal{L}^{(b)}_{\text{RemixIT}} = \mathcal{L}(\hat{\mathbf{s}}_b, \tilde{\mathbf{s}}_b) + \mathcal{L}(\hat{\mathbf{n}}_b, P\tilde{\mathbf{n}}_b), \quad b \in {1,\dots,B}$$ $$\mathcal{L}_{\text{RemixIT}} = \sum_{b=1}^{B} \left[ \mathcal{L}(\hat{\mathbf{s}}_b, \tilde{\mathbf{s}}_b) + \mathcal{L}(\hat{\mathbf{n}}_b, P\tilde{\mathbf{n}}_b) \right] \tag{6}$$

用いる損失関数は教師あり設定 (式2) と類似しているが、**グラウンドトゥルースのクリーン音源波形の代わりに、教師ネットワークが提供するノイジーな推定 $\tilde{\mathbf{s}}$ と $\tilde{\mathbf{n}}^{(P)}$ を用いる**点が異なる。信号レベル損失 $\mathcal{L}$ が推定信号と目標信号の間のユークリッドノルムも最小化する場合、提案コスト関数はいくつかの収束特性を享受し、教師の推定がグラウンドトゥルース音源波形に近くない場合でも頑健な SSL 学習を可能にする。

最後に、RemixIT は最新の利用可能な生徒モデルの重みを用いて教師ネットワーク $f_T$ の推定を洗練する。本研究で用いる継続的更新プロトコルは**逐次更新**と**移動平均更新**である (III-C 節参照)。

#### 2) ユークリッドノルム下での誤差解析

各最適化ステップで RemixIT は生徒の推定と教師の疑似目標の間の信号レベル損失を最小化する。雑音除去に主に関心があるため、初期混合 $M$ とブートストラップ混合 $\tilde{M}$ をそれぞれ入力とする教師と生徒ネットワークの音声推定に着目する。これらは確率変数として次のように表せる:

$$\tilde{S} = f^{(\tilde{s})}_T(M = S + N; \theta^{(k)}_T), \quad M \sim \mathcal{D}_m$$ $$\hat{S} = f^{(\hat{s})}_S(\tilde{M} = \tilde{S} + \tilde{N}^{(P)}; \theta^{(k)}_S) \tag{7}$$

初期クリーン目標 $S$ に対する教師の誤差 $\tilde{R}_T$ と生徒の誤差 $\hat{R}_S$ は次の条件付き確率である:

$$\tilde{R}_T = \tilde{S} - S, \quad \hat{R}_S = \hat{S} - S$$ $$\tilde{R}_T \sim P(\tilde{R}_T | S, N), \quad \hat{R}_S \sim P(\hat{R}_S | \tilde{S}, \tilde{N}, P) \tag{8}$$

式(6)で推定信号と目標信号の二乗誤差を最小化する信号レベル損失 $\mathcal{L}$ を用い、推定信号と目標信号が単位ノルム $|s| = |\tilde{s}| = |\hat{s}| = 1$ であると仮定すると、RemixIT の損失関数は以下の最小化と等価になる:

$$\mathcal{L}_{\text{RemixIT}} \propto \mathbb{E}[|\hat{S} - \tilde{S}|_2^2] = \mathbb{E}[|(\hat{S} - S) - (\tilde{S} - S)|_2^2]$$ $$= \underbrace{\mathbb{E}[|\hat{R}_S|_2^2]}_{\text{教師あり損失}} + \underbrace{\mathbb{E}[|\tilde{R}_T|_2^2]}_{\theta_S \text{に関して定数}} - 2\underbrace{\mathbb{E}[\langle \hat{R}_S, \tilde{R}_T \rangle]}_{\text{誤差の相関}} \tag{9}$$

**理想的には、最後の内積項がゼロであれば、この損失は教師あり設定と同じ最適化目的に帰着する** (中間項は $\theta_S$ に関する勾配計算でゼロになるため)。$\langle \hat{R}_S, \tilde{R}_T \rangle = 0$ は、教師がクリーン目標信号と区別できない出力を生成するか、式(8)の条件付き誤差分布が独立である場合に達成される。直感的には、教師モデルを継続的に更新しその推定を洗練するにつれて教師誤差のノルムが最小化され、生徒からのより高忠実度の再構成につながる。

さらに、**ブートストラップ再混合プロセスは誤差をより無相関にすることを強制する**。生徒は教師と同様に同じクリーン音声信号 $s$ の再構成を試みるが、**異なる混合分布のもとで**行うためである。形式的には、生徒はブートストラップ混合 $\tilde{\mathbf{m}} = \tilde{\mathbf{s}} + \tilde{\mathbf{n}}^{(P)}$ を観測しながら $s$ の再構成を試み、教師は初期入力混合 $\mathbf{m} = \mathbf{s} + \mathbf{n}$ のみから $s$ の再構成を試みる。

単一の音声信号 $s^*$ の再構成に着目すると:

$$\tilde{s}^_, \tilde{n}^_ = f_T(m^* = s^* + n^_; \theta_T)$$ $$\tilde{s}'_b, \tilde{n}'_b = f_T(m'_b = s'_b + n'_b; \theta_T)$$ $$\tilde{m}'_b = \tilde{s}^_ + \tilde{n}'_b, \quad \forall b \in {1,\dots,B} \tag{10}$$

RemixIT の損失は期待値の下で計算される (式9) ため、生徒ネットワークが見るバッチの順序を並べ替えることができる。誤差相関項は次のように書き換えられる:

$$\mathbb{E}[\langle \hat{R}_S, \tilde{R}_T \rangle] \approx \mathbb{E}\left[ \frac{1}{B}\sum_{b=1}^{B}(\hat{s}_b - s^_)^\top(\tilde{s}^_ - s^_) \right]$$ $$= \mathbb{E}\left[(\tilde{s}^_ - s^*)^\top \underbrace{\frac{1}{B}\sum_{b=1}^{B}\left( f^{(\hat{s})}_S(\tilde{s}^* + \tilde{n}'_b; \theta_S) - s^* \right)}_{\text{経験的平均生徒誤差}} \right] \tag{11}$$

前提となるのは、**生徒が同じ教師の音声推定 $\tilde{s}^*$ から生成された多様なブートストラップ混合を見るならば、ノイジーな教師推定 $\tilde{n}'_b$ を注入することで生じる平均干渉誤差は期待値の下でゼロに向かう**ということである。

#### 定理 II.1

> 損失関数の微分可能性、教師ネットワーク $f_T$ が生成する無限個のブートストラップ混合 $B \to \infty$ へのアクセス、および同じ教師音声疑似目標が与えられたときの生徒誤差の条件付き独立性 ($i \neq j$ に対して $f^{(\hat{s})}_S(\tilde{s}^* + \tilde{n}'_i; \theta_S) - \tilde{s}^* \perp f^{(\hat{s})}_S(\tilde{s}^* + \tilde{n}'_j; \theta_S) - \tilde{s}^*$) を仮定すると、生徒ネットワークの重み $\theta_S$ に関する RemixIT 損失関数の勾配は、オラクル教師あり損失が与える勾配に収束する: $\nabla_{\theta_S}\mathcal{L}_{\text{RemixIT}} \approx \nabla_{\theta_S}\mathcal{L}_{\text{Supervised}}$

**証明の概要**

式(2)と(6)の損失関数の定義を組み合わせると、その差は次のように表せる:

$$\mathcal{L}_{\text{RemixIT}} - \mathcal{L}_{\text{Supervised}} = \mathbb{E}\left[|\tilde{R}_T|_2^2 - 2\langle \hat{R}_S, \tilde{R}_T \rangle\right] \tag{12}$$

誤差相関項を展開すると:

$$\mathbb{E}[\langle \hat{R}_S, \tilde{R}_T \rangle] = \mathbb{E}\left[(\tilde{s}^* - s^_)^\top \tfrac{1}{B}\sum_b (\hat{s}_b - s^_)\right]$$ $$= \mathbb{E}[|\tilde{R}_T|_2^2] + \mathbb{E}\left[(\tilde{s}^* - s^_)^\top \tfrac{1}{B}\sum_b (\hat{s}_b - \tilde{s}^_)\right] \tag{13}$$

線形基底上で動作する任意のマスクベースのネットワーク (本研究では線形エンコーダ/デコーダを使用) について、教師の疑似目標 $\tilde{s}^*$ と生徒の推定音声信号 $\hat{s}'_b$ の誤差は有界である。入力ブートストラップ混合の符号化表現を $v' = P \cdot m'$、信号推定の潜在表現を $\hat{v} = \hat{M} \odot (P \cdot m')$ とすると、$l_2$ 誤差は次のように有界となる:

$$|\hat{s}'_b - \tilde{s}^_| = |(\hat{M}'_b - \tilde{M}^_) \odot (P \cdot \tilde{m}'_b)| \leq \max \left[\sigma_{\max}{(\hat{M}'_b - \tilde{M}^_) \odot P} \cdot |\tilde{s}^_ + \tilde{n}'_b|\right] = \hat{C} \tag{14}$$

ここで $\sigma_{\max}{\cdot} < \infty$ はマスクされた展開合成基底行列の最大特異値、$|\tilde{s}^* + \tilde{n}'_b| < \infty$ は有界ノルムのブートストラップ混合のエネルギーである。同様に教師誤差も $|\tilde{s}^* - s^*| \leq \tilde{C} < \infty$ で有界である。

したがって極限において損失関数の差は $\theta_S$ に関して定数の値に収束する:

$$\lim_{B \to \infty}[\mathcal{L}_{\text{RemixIT}} - \mathcal{L}_{\text{Supervised}}] = -\mathbb{E}[|\tilde{R}_T|_2^2] + \lim_{B\to\infty}\mathbb{E}_{\tilde{s}^_}\left[(\tilde{s}^_ - s^_)^\top \mu(\tilde{s}^_)\right] \tag{15}$$

最後のステップは**中心極限定理**の適用による。仮定により生徒の推定誤差は i.i.d. かつ有界であるため、標本平均は平均生徒誤差 $\mu(\tilde{s}^*)$ を平均とする正規分布に分布収束する。右辺のすべての項が最適化対象の $\theta_S$ に関して定数であるため、勾配演算子を適用すると $\nabla_{\theta_S}\mathcal{L}_{\text{RemixIT}} \approx \nabla_{\theta_S}\mathcal{L}_{\text{Supervised}}$ が結論される。∎

（生徒誤差が弱従属である現実的な設定への拡張は将来課題として残されている。）

### B. 音声強調モデル

- 教師あり および RemixIT の学習レシピでは、生徒は $M = 2$ 出力スロットを持ち、常に音声成分とノイズ源を推定する
- MixIT で学習するモデルでは、追加のノイズ成分を推定するため出力スロットを $M = 3$ に増やす
- **RemixIT は音声強調モデルのアーキテクチャの選択に依存しない** (入力混合の音声成分とノイズ成分の両方を推定する限り)

本研究では **Sudo rm -rf** アーキテクチャを、group communication による共有サブバンド処理を用いたよりスパースな計算ブロックとともに使用した。このネットワークは音声強調および音源分離タスクで高品質な音源推定を提供しつつ、モデルサイズを大幅に削減することが示されている。

**設定**: エンコーダ/デコーダは 512 基底、41 フィルタタップ、ホップサイズ 20 時間サンプル、深さ $U = 8$ U-ConvBlocks。逐次更新プロトコルでは新しい生徒ネットワークの深さを20エポックごとに 8 → 16 → 32 と増やす。

### C. 教師更新プロトコルの設定

$k$ 学習エポック後の各種オンライン教師更新プロトコル:

- **静的教師 (Static teacher)**: 教師は学習を通じて凍結。全最適化ステップで $\theta^{(k)}_T = \theta^{(0)}_T$
- **逐次更新教師 (Sequentially updated teacher)**: 20エポックごと (すなわち $K = 20 \times |\mathcal{D}_m|/B$ 最適化ステップごと) に、教師を最新の生徒で置き換える: $\theta^{(k \bmod K)}_T := \theta^{(k \bmod K)}_S$
- **指数移動平均教師 (EMA teacher)**: 各エポック後に指数移動平均で漸進的に更新。$\bar{\theta}^{(j+1)}_T := \gamma\theta^{(j)}_S + (1-\gamma)\bar{\theta}^{(j)}_T$、$\gamma = 0.01$、$j$ は $|\mathcal{D}_m|/B$ の倍数

### D. 学習・評価の詳細

損失関数には**負の SI-SDR (scale-invariant signal to distortion ratio)** を採用:

$$\mathcal{L}(\hat{y}, y) = -\text{SI-SDR}(\hat{y}, y) = -20\log_{10}\left(\frac{|\alpha y|}{|\alpha y - \hat{y}|}\right) \tag{16}$$

$\alpha = \hat{y}^\top y / |y|^2$ により、推定音源 $\hat{y}$ と目標信号 $y$ のスケールに対して損失が不変になる。$\alpha = 1$ とすると SI-SDR は SNR と等価になる。

**ハイパーパラメータ**:

- 最適化器: Adam
- バッチサイズ: $B = 2$
- 初期学習率: $10^{-3}$、6エポックごとに 1/2 に減衰
- サンプリングレート: 16 kHz
- 全入力混合波形は平均を引き標準偏差で割って正規化

学習中は入力 SNR 分布へのアクセスがないと仮定し、クリーン音源とノイズ源をそのパワー比を変えずに混合する。ただし DNS でのドメイン内教師あり学習設定では、$[-2, 20]$ dB の一様分布から SNR をサンプリングしてランダムに混合する。

**評価指標**: SI-SDR、STOI (短時間客観的了解度)、PESQ (音声品質の知覚的評価)。事前学習教師と教師ありモデルは100エポック後、その他の構成は60エポック後のチェックポイントを評価。

## IV. 結果と考察

### A. 教師の推定の継続的洗練の必要性

図2では、静的教師または20エポックごとの逐次更新教師が生成する生徒モデルの音声強調性能を示している。

- すべてのプロトコルは同じ初期教師を使うため、20エポック目までは同様に振る舞う
- 20エポック目以降、古い教師が新しく学習された $U=8$ の生徒で置き換えられ、深さが倍 ($8 \to 16$) の新しい生徒が初期化される
- **驚くべきことに、逐次更新教師プロトコルは40エポック目以降もより良い生徒分離モデルを教え続ける**のに対し、静的教師が生成する両モデルは同じ学習ステップ数で飽和する
- 静的教師による $U=8$ と $U=16$ の生徒を比較すると、より表現力の高い生徒の方が性能が良いが、逐次更新教師プロトコルが生成する同じ深さの生徒には及ばない
- 40エポック目の時点で同じ深さ ($U=16$) の生徒モデル同士を比較しても、逐次更新プロトコルが凍結教師プロトコルを明らかに上回る

したがって、**ブートストラップ再混合と教師の推定の継続的洗練の組み合わせこそが、RemixIT がもたらす顕著な改善の鍵**である。この結果を受け、逐次更新教師プロトコルを RemixIT のデフォルト戦略として採用した。ただしゼロショット適応では、利用可能な学習混合数が少ないため、ゼロから学習すると生徒が過学習しやすくなることから、指数平均教師更新スキームを用いる。

### C. ゼロショットドメイン適応 (図 4)

低リソース学習シナリオでは、手持ちの学習混合がゼロからモデルを学習させるのに不十分な場合がある。RemixIT はゼロショット教師なしドメイン適応アルゴリズムとして使用できる。

**手順**: より大きな OOD データセットで教師を事前学習し、限られたドメイン内混合で生徒モデルをファインチューニングする。適応プロセス開始時、生徒は事前学習教師の重みで初期化され ($\theta^{(0)}_S := \theta^{(0)}_T$)、移動平均プロトコルで教師を周期的に更新しながら RemixIT を実行する。

**結果**: データセットと事前学習手法を横断して一貫した改善が得られ、キャリブレーションなしのモデルに対して SI-SDR で最大 **0.8 dB** の改善。改善の度合いは利用可能なノイズ混合の量に直接影響される (WHAM! テストは3,000混合で大きな利得、DNS は150混合のみで小さな利得)。

しかし RemixIT は、学習セットと適応テストセットの間に大きな分布シフトがある場合 (WHAM! は10クラスの都市背景ノイズのみ、DNS は非常に多様) でも十分に機能する。特に、WHAM! で教師あり事前学習したモデルを非常に多様な DNS セットの150混合に適応させた際の顕著な改善は、**極めて困難なゼロショット学習条件下での RemixIT の有効性**を示している。

### D. 生徒の学習の進行 (図 3)

DNS 学習セット上で RemixIT で学習された生徒モデルが、学習の進行に伴って推定をどう洗練し、初期教師とどう比較されるかを分析。

- 生徒は、**初期教師がより良く機能する領域において**、徐々に初期教師より良い性能を発揮するようになる (行ごとの右端のプロット)。ただし非常に良い推定 (例: 15 dB 超) に対する改善はより困難になる
- 教師ネットワークが最新の生徒の重みで更新される RemixIT の継続的自己学習スキームが、より大きな性能向上の鍵であることが明白
- この結果は OOD 教師あり教師と MixIT 教師の両方で成立し、**II-C2 節の理論解析 (より良い教師が RemixIT 損失関数の誤差相関項を減少させ、教師あり学習に近づける) と整合**する
- 対照的に、低性能ブラケット (教師 SI-SDR が $[-30, -10]$ dB) では、更新された教師の推定波形に回帰しても生徒は性能をさらに向上させる方法を学習できない。この学習パターンの出現は、教師ネットワークが極めてノイジーな推定を提供する場合から回復できる、より頑健な自己学習アルゴリズムの発見の必要性を示唆する

### E. 非常にノイジーな教師の推定での頑健な学習 (図 5)

教師モデルが低品質な音声推定 $\tilde{s}$ を出力する場合の RemixIT の頑健性を調査。生徒が、**同じ教師の音声推定 $\tilde{s}$ と独立した教師のノイズ推定 $\tilde{n}'_b$ から生成された複数のブートストラップ混合** $\tilde{m}'_b = \tilde{s} + \tilde{n}'_b$ で学習されることの重要性を再確認する。

10エポック学習後の経験的平均生徒が初期教師に対して生む SNR 性能改善の分布を、入力ブートストラップ混合数を掃引しながら示した:

- 教師あり教師と MixIT 教師の両ケースで、ブートストラップ混合数 $B$ を 1 から 64 に増やすと**平均 SNR 改善は約 2 dB** になる
- 注目すべきは、この結果が**非常に悪い教師推定 (5 dB 未満) に対しても成立**し、しかも生徒パラメータを洗練させることなく、単に $\tilde{s}$ のより多くの拡張に対して推論を実行するだけで得られること

すべての音声推定とグラウンドトゥルース信号が単位ノルム $|s| = |\tilde{s}| = |\hat{s}_b| = 1$ であると仮定すると、SNR の最大化は $l_2$ ノルムの最小化と等価になる ($\text{SNR}(\hat{y}, y) \propto -|\hat{y} - y|$)。結果として、経験的平均生徒の平均 SNR 改善は $\mathbb{E}[\langle \hat{R}_S, \tilde{R}_T \rangle]$ 項をゼロに近づけ (式11)、**教師の誤差項 $|\tilde{R}_T|$ がゼロから遠い場合でも生徒がより頑健に学習する**ことにつながる。

### F. クロスドメイン汎化 (表 II, III)

#### 表 II: 自己教師あり学習の平均 SI-SDR 改善 (dB)

MixIT とその変種は、ノイズ分布 $\mathcal{D}_n$ が真のドメイン内分布 $\mathcal{D}^*_n$ に近くない場合に汎化に失敗する。注目すべきは、**RemixIT がドメイン内データセットにアクセスすることなくすべての MixIT 手法を上回る**ことである。

主な結果:

- WHAM! (W!) の混合と LFSD (L) のノイズ源のみが利用可能な場合、最良のノイズ拡張 MixIT モデルは適応 WHAM! データセットで **1.6 dB** の SI-SDR 改善しか得られない。対照的に、LFSD で MixIT 事前学習した教師を持つ RemixIT は、最良のクロスデータセット学習 MixIT モデルに対し **5.3 dB (1.6 → 6.9)**、教師モデルに対し **0.7 dB (6.2 → 6.9)** の改善を達成
- LFSD のノイズサンプルと LFSD + WHAM! の混合サンプルという非常に厳しいミスマッチのケースでも、RemixIT はすべてのデータセットで強い結果 (DNS 4.9 dB、LFSD 7.2 dB、WHAM! 6.9 dB) を示す。一方、最良の MixIT 構成でさえ入力混合に対する有意な改善を生めない (DNS 1.7 dB、LFSD **−1.7 dB**、WHAM! 1.6 dB)
- RemixIT は他の目標混合データセットを活用することで**ソースデータセットのテストセットでも教師モデルの性能を改善できる**。多様な教師なし DNS 混合データセットでの自己学習により、LFSD 事前学習教師に対して LFSD テストセットで **1.4 dB (8.5 → 9.9)** の改善
- 驚くべきことに、RemixIT は **WHAM! のデータを一切見ていないにもかかわらず** WHAM! テストセットで教師を大差 (6.2 → 8.2 dB) で上回った。これは RemixIT が未知データへの雑音除去モデルの汎化にシームレスな解を提供できることを示す

RemixIT は $L \to W!$ の適応でよりクリーンなデータセットへの適応 ($L \to D$: 7.5 → 6.8) と比べてわずかな性能低下を示すが、同じ MixIT 構成は雑音除去性能に大打撃を受ける (5.3 → 1.2 dB on W!) ことに注意されたい。本質的に、**WHAM! の入力 SNR (−1.3 dB) が自己教師ありアルゴリズムの効果的な学習を妨げており、OOD だが入力 SNR の高いデータセット (例: DNS) での学習の方が良い結果につながる**。

#### 表 III: 半教師ありドメイン適応

RemixIT は、DNS からはるかに多様性が低く入力 SNR も低い WHAM! への知識転移のような、著しくミスマッチしたケースでも半教師ありドメイン適応を適切に実行する。WHAM! での OOD 半教師あり教師 (性能 6.1 dB とかなり劣る) から出発して、DNS テストセット上でクリーンなドメイン内音源信号なしでの最良性能モデル (**7.3 dB**) を達成した。

### G. ドメイン内ノイズ録音を用いる RemixIT (図 6)

最後に、利用可能な分離ドメイン内ノイズ録音 $\mathbf{n} \sim \mathcal{D}_n$ を活用して RemixIT の性能をさらに高める拡張を提案する。式(5) のブートストラップ再混合プロセスを、教師のノイズ推定の代わりにドメイン内ノイズ録音の一部を用いるように変更する:

$$\tilde{m}_b = \tilde{s}_b + \zeta n_b + (1 - \zeta)\tilde{n}^{(P)}_b, \quad \zeta \sim \text{Bernoulli}(p_n) \tag{17}$$

ここで $p_n$ は、対応するバッチインデックスに対して教師の推定の代わりにドメイン内ノイズ録音をサンプリングするベルヌーイパラメータである。

**結果**:

- ドメイン内ノイズ録音と混合データの比 $p_n = |\mathcal{D}_n|/(|\mathcal{D}_n| + |\mathcal{D}_m|)$ に設定
- RemixIT は同じドメイン内ノイズ録音比率のファインチューニング MixIT より一貫して良い性能を示す。例外は最右端の点で、ブートストラップ混合の多様性が低くなり、生徒モデルが少量の人間発話にしか過学習しなくなる
- **注目すべきは、RemixIT が生徒モデルをゼロから完全に学習させているのに対し、ファインチューニング MixIT はより多くの学習可能パラメータ (0.97M vs 0.56M) を持ち、しかも LFSD MixIT チェックポイントからのウォームスタートを享受している**点である
- 汎化データセット (DNS, WHAM!) においては、教師ありデータが多いほど提案拡張は良くなる
- $|\mathcal{D}_n| = |\mathcal{D}_m|$ に保ちベルヌーイパラメータを $p_n: 0.01 \to 0.5$ と漸増させるアブレーションでは、SI-SDRi が DNS テストセットで 6.1 → 6.4 dB、WHAM! で 8.6 → 9.0 dB に改善。これは**よりクリーンなノイズ推定が、干渉の少ないブートストラップ混合の合成を通じてより強い利得につながる**という主張を裏付ける

## V. 結論

本論文では、教師ネットワークと生徒ネットワークの間の**生涯的な双方向パラメータ更新**に基づく音声強調モデルの自己学習スキームを提示した。

提案フレームワークは、**ブートストラップ再混合**と**教師出力の継続的洗練**を通じて、ドメイン外データで事前学習されたモデルの知識を適切に転移する。

主な成果:

- 本手法が従来のすべての SOTA な自己教師あり手法を大幅に上回りつつ、より汎用的でドメイン内データへの依存がないことを実験的に示した
- RemixIT が限られたドメイン内混合で半教師ありおよびゼロショットドメイン適応の設定も実行できることを示した
- 理論解析が実証結果に裏付けられており、**特に極めてノイジーな疑似目標信号でもなお学習できる領域における教師–生徒の学習ダイナミクスの理解に有用**である

**今後の課題**: 疑似目標の品質に対する信頼度ベースの代理指標を推定することによるアルゴリズムの頑健性の強化、および異なるドメインへの適用による手法の適用範囲の拡大。
