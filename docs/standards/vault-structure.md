## Vault Structure

このファイルは、Obsidian vault の分類、配置、命名、タスク管理に関する正本である。ノート本文の形式は `note-format.md`、エージェントの作業規約はルートの `AGENTS.md` を参照する。

## 大方針

- 人間は `00_Inbox/` に殴り書きするだけでよい。
- AIエージェントは分類・整形・移動・命名・タグ・リンク・MOC・索引更新を提案し、承認後に実行する。
- 複数ファイルの作成・削除・リネームなど大きな整理では、作業前コミットを提案する。
- 書き込み前に `docs/agents/coordination.md` に従って排他ロックを取得する。

## フォルダ構成

| フォルダ | 用途 |
|---|---|
| `00_Inbox/` | 未整理ノートの一時置き場 |
| `10_Projects/` | 期限・ゴールのあるアクティブな作業 |
| `20_Areas/` | 継続的に管理するトピック |
| `20_Areas/大学授業/` | 大学で履修する授業・課題・講義回ごとのノート |
| `20_Areas/永続ノート/` | Zettelkasten 永続ノート |
| `30_Resources/` | 将来再利用できる参考資料・論文メモ |
| `30_Resources/講座/` | 外部講座・公開講義・MOOCなど学習元に紐づく記録 |
| `40_Archives/` | 完了・不要なノート |
| `99_Templates/` | Templater テンプレート |

PDF本体はvaultに置かず、Zoteroなどの外部で管理する。

## 学習ノートの分類

フォルダはノートの役割で決め、学習元と知識分野を同じ階層だけで表現しない。

| 内容 | 行き先 |
|---|---|
| 未整理の単発メモ | `00_Inbox/` |
| 期限・完了条件がある学習活動 | `10_Projects/` |
| 大学で履修する授業・課題 | `20_Areas/大学授業/` |
| 外部講座・公開講義・MOOCの講義記録 | `30_Resources/講座/` |
| 書籍・論文・記事・動画など出典に紐づく記録 | `30_Resources/` の該当フォルダ |
| 複数の出典から再利用できる分野知識 | `20_Areas/` の該当分野 |
| 複数分野に通じる抽象的な知見 | `20_Areas/永続ノート/` |

- 外部講座の記録を `20_Areas/` に直接置かない。講座に依存しない知識へ書き直した段階で、該当分野のノートへ統合する。
- 単発情報はまず `00_Inbox/` に置き、出典保存が必要なら `30_Resources/`、一般化できるなら `20_Areas/` へ移す。
- 出典ノートと分野ノートは、`出典`・`関連`のWikiリンクで相互に接続する。
- 学習元を区別する必要があるノートには `source_type` と `source` を付ける。

| `source_type` | 学習元 |
|---|---|
| `university-course` | 大学授業 |
| `external-course` | 外部講座・公開講義 |
| `book` | 書籍 |
| `paper` | 論文 |
| `article` | Web記事 |
| `video` | 動画 |
| `personal` | 自分の考察 |

## タスク管理

- 実行可能なタスクはMarkdownの未完了チェックボックス `- [ ]` で記述する。
- 期限があるタスクには `📅 YYYY-MM-DD` を付ける。AIエージェントは期限を推測して追加しない。
- 優先度は `⏫`（最優先）、`🔼`（優先）、記号なし（通常）、`🔽`（低優先）を使う。
- 完了したタスクは `- [x]` にする。AIエージェントはユーザーの確認なしに完了扱いへ変更しない。
- 朝のタスクレポートでは `00_Inbox/`、`10_Projects/`、`20_Areas/大学授業/` を対象とし、知識ノート、テンプレート、運用ドキュメントは除外する。
- 空のチェックボックス、コードブロック内、例示用チェックボックスはタスクとして扱わない。

```markdown
- [ ] 教師モデルの事前学習 ⏫ 📅 2026-07-16
- [ ] 関連論文を整理する 🔽
```

毎朝の集計・報告手順は `docs/workflows/daily-task-report.md`、Slack・Hermes・Google Calendar連携は `docs/integrations/slack-hermes.md` に従う。

## 触れてはいけないもの

- `.obsidian/` は原則編集しない。
- 例外は `.obsidian/snippets/vault-custom.css` のCSS編集のみである。
- `99_Templates/` はユーザーが明示した場合だけ編集する。
- `*.pdf` などのバイナリは操作しない。

## 命名規則

大原則は、時間軸のノートには日付を付け、知識ノートには付けないことである。

| 種別 | 命名規則 | 例 |
|---|---|---|
| 知識ノート | `概念名.md` | `決定木.md` |
| MOC | `【MOC】タイトル.md` | `【MOC】HPA.md` |
| 論文読書メモ | `略称_メモ.md` | `TF-Locoformer_メモ.md` |
| 実験ログ | `YYYYMMDD_タイトル.md` | `20260511_音源分離実験.md` |
| 勉強会 | `YYYYMMDD_勉強会NN.md` | `20260423_勉強会02.md` |
| 執筆ドラフト | `YYYYMMDD_タイトル_draft.md` | `20260601_中間報告スライド_draft.md` |
| 週次レビュー | `YYYY-Www_週次レビュー.md` | `2026-W23_週次レビュー.md` |
| 月次レビュー | `YYYY-MM_月次レビュー.md` | `2026-06_月次レビュー.md` |
| 日次ノート | `YYYY-MM-DD.md` | `2026-05-12.md` |

手動作成するログ類は `YYYYMMDD_` を使う。Periodic Notesが作る日次・週次・月次はISO形式を使う。
