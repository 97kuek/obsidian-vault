## Proofread

指定されたフォルダまたはファイルの文章を添削する。分類・移動・命名変更ではなく、既存ノートの読みやすさを上げるための整形を行う。

## 対象

- ユーザーが指定した Markdown ファイル
- ユーザーが指定したフォルダ配下の Markdown ファイル
- 対象指定がない場合は、どのファイルを添削するか短く確認する

## 原則

- 元情報を削らない。
- 事実関係、数式、コード、引用、リンク先を勝手に変えない。
- だ・である調に統一する。
- 箇条書き中心にする。
- 比較、分類、手順、対応関係は表にする。
- コマンド、コード、設定、ログ、ファイル構造はコードブロックにする。
- 長い一文は分割する。
- 口語、重複、あいまいな指示語を整理する。
- 見出しは `##` から始め、`#` は使用しない。
- `###` 以下の見出し階層を整える。
- Markdown と Obsidian の Wiki リンクを壊さない。

## コロンの扱い

ユーザーが「コロンを使わない」「：を使わない」と指定した場合は、本文中の半角コロンと全角コロンを避ける。

ただし、次は意味や構文を壊すため原則として残す。

- YAML frontmatter のキー区切り
- URL
- Windows パスのドライブ表記
- 時刻
- コードブロック内のコードやログ
- 数式内の記法

本文で説明に使っているコロンは、見出し、箇条書き、表、読点、括弧表現に置き換える。

## 対象確認

編集前に次を確認する。

1. `VAULT_INDEX.md` を読んで対象候補を確認する
2. `docs/standards/vault-rules.md` を読んで文体と frontmatter 規約を確認する
3. `git status --short` で既存変更を確認する
4. 対象ファイルだけを読む

フォルダ指定で対象が多い場合は、対象一覧を提示してから実行する。目安として 10 ファイルを超える場合は確認を挟む。

## 編集範囲

原則として本文だけを添削する。

次は必要がない限り編集しない。

- frontmatter
- `publish` 設定
- タグ
- ファイル名
- MOC
- `VAULT_INDEX.md`
- `.obsidian/`
- `99_Templates/`

ファイル追加、削除、リネーム、移動を行う場合は、添削ではなく整理作業として扱い、ユーザーに確認する。

## 整形ルール

### 文章

- です・ます調を、だ・である調に直す。
- 「これ」「それ」「あれ」は、指す対象が分かる語に置き換える。
- 「すごい」「いい感じ」「やばい」などの曖昧語は、具体的な意味に直す。
- 同じ内容の重複は統合する。ただし情報は落とさない。
- 主語と述語の対応を整える。

### 箇条書き

- 1 項目 1 内容にする。
- 階層は深くしすぎない。
- 並列な項目は品詞や文末をそろえる。
- 手順は番号付きリストにする。
- 単なる羅列ではなく、必要に応じて見出しを分ける。

### 表

次の内容は表にする。

- 用語と意味
- 手法の比較
- メリットとデメリット
- 入力と出力
- 条件と対応
- 役割分担
- 手順と目的

表にすると読みにくくなる長文説明は、表に詰め込まず本文に分ける。

### コードブロック

次の内容は fenced code block にする。

- シェルコマンド
- 設定ファイル
- プログラムコード
- ログ出力
- ディレクトリ構造
- JSON、YAML、TOML などの構造化データ

言語が分かる場合は info string を付ける。

````markdown
```powershell
git status --short
```
````

### 数式

- 数式は意味が変わりやすいため、原則として内容を変えない。
- インライン数式とブロック数式の使い分けを整える。
- 数式の前後に、その式が何を表すかを短く説明する。

## 実行手順

1. 対象ファイルを特定する
2. 既存変更を確認する
3. 対象ファイルを読む
4. 添削方針を短く述べる
5. 対象ファイルを編集する
6. Markdown 構文、Wiki リンク、指定禁止文字を必要に応じて確認する
7. 変更内容を簡潔に報告する

## 確認コマンド例

半角コロンを避ける指定がある場合。

```powershell
Select-String -Path <target> -Pattern ':'
```

全角コロンを避ける指定がある場合。

```powershell
Select-String -Path <target> -Pattern '：'
```

Markdown ファイル一覧を確認する場合。

```powershell
rg --files <folder> -g "*.md"
```

## 完了報告

```markdown
## 添削完了

- 対象: ...
- 変更: だ・である調、箇条書き、表、コードブロックを中心に整形
- 確認: コロン指定、Markdown 構文、差分確認など
- 未対応: あれば記載
```
