## Daily Task Report

毎朝、その日に注意すべきタスクをVaultから抽出し、読み取り専用で報告する。

## 安全境界

- ファイルの作成、編集、移動、削除を行わない。
- タスクを完了扱いにしない。
- 期限や優先度を推測して追加しない。
- Git操作、外部投稿、メッセージ送信以外の外部操作を行わない。
- 読み取り専用なのでエージェントロックは取得しない。

## 対象

- `00_Inbox/`
- `10_Projects/`
- `20_Areas/大学授業/`

## 除外

- `20_Areas/` のうち大学授業以外の知識ノート
- `30_Resources/`
- `40_Archives/`
- `99_Templates/`
- `docs/`、`README.md`、`AGENTS.md`、`CLAUDE.md`、`HERMES.md`
- コードブロック内のチェックボックス
- 本文が空の `- [ ]`
- 明らかな記法例・サンプル
- 完了済みの `- [x]`

## タスク記法

```markdown
- [ ] タスク本文 ⏫ 📅 YYYY-MM-DD
```

| 記法 | 意味 |
|---|---|
| `📅 YYYY-MM-DD` | 期限 |
| `⏫` | 最優先 |
| `🔼` | 優先 |
| 記号なし | 通常 |
| `🔽` | 低優先 |

## 判定順

1. 期限超過
2. 今日が期限
3. `⏫` のタスク
4. 今日から7日以内に期限が来るタスク
5. `10_Projects/` にある期限なしの未完了タスク
6. `00_Inbox/` と `20_Areas/大学授業/` にある期限なしタスク

同じ区分では、優先度、期限、ファイルパスの順で並べる。期限なしタスクは全件を列挙せず、最優先候補を最大5件に絞る。

## 抽出ツール

最初にVaultルートで次を実行し、構造化された候補を取得する。

```zsh
ruby tools/collect-daily-tasks.rb
```

- JSONの `path`、`line`、`task`、`due`、`priority` を根拠として分類する。
- 抽出結果が空の場合、対象フォルダを無制限に再探索しない。
- ツールが失敗した場合だけ、対象フォルダを `rg` で読み取り検索する。

## Slackレポート形式

```markdown
☀️ *今日のタスク｜M/D*

☐ タスク1
  ↳ 出典ノート

☐ タスク2
  ↳ 出典ノート

☐ タスク3
  ↳ 出典ノート

⚠️ *期限あり*
☐ M/D タスク — 出典ノート

_未完了 N件・期限設定 N件_
```

- 最初に今日の候補を最大3件だけ表示する。
- `☐` を各タスクの先頭に付け、タスク間を改行する。
- タスク本文は1行に要約し、補足を詰め込みすぎない。
- 出典はファイル名から拡張子と `【MOC】` を除いた短い名前だけを表示する。Obsidian Wikiリンク、絶対パス、行番号はSlack本文へ出さない。
- 期限超過・今日・7日以内のタスクがある場合だけ `⚠️ *期限あり*` を表示する。該当しないセクションや「なし」は表示しない。
- 「今日の候補」と「期限あり」で同じタスクを重複表示しない。
- 期限なし候補の選択は提案であり、ユーザーの決定として扱わない。
- 末尾は未完了件数と期限設定件数の1行だけにする。
- タスクが0件なら `☀️ *今日のタスク｜M/D*\n\n今日は登録タスクなし` とだけ報告する。
- Vaultを変更しなかった旨など、毎回同じ安全説明は本文へ書かない。

## Google Calendar連携時

- Calendar認証が完了している場合だけ、今日の予定を読み取る。
- タスク候補の前に、現在時刻以降の予定を最大3件、開始時刻と件名だけで表示する。
- 終日予定、締切、時間指定予定を区別する。
- 予定と期限付きタスクが重なる場合だけ注意を1行追加する。
- 予定の作成、変更、削除は行わない。

## cron運用

- 毎日9:00、Macのローカルタイムで実行する。
- 作業ディレクトリはVaultルートに固定する。
- Slackの自分専用DMをホーム通知先にする。
- 同一内容のcronを重複登録しない。
- エラーが連続する場合はジョブを一時停止し、ユーザーへ報告する。
- 毎週日曜18:00に、期限なしを含む未完了タスクから「今週の主要3件」の候補をSlack DMへ提示する。
- 週次候補はVaultを書き換えず、ユーザーが採用番号と期限を返した後に別作業として反映する。
