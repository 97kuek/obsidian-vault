## 画像・スクリーンショットの添付

画像はvault直下の `attachments/` にまとめる。Obsidianへクリップボードから貼り付けた画像も、同じフォルダへ保存する。

## 初期設定

Obsidianで次を設定する。

1. `設定` → `ファイルとリンク` を開く。
2. `新規添付ファイルの作成場所` で `以下で指定されたフォルダ` を選ぶ。
3. 保存先に `attachments` を指定する。
4. `新規リンクの形式` は `可能な限り最短のパス` を使う。
5. `内部リンクを常に更新する` を有効にする。

設定後、画像を1枚貼り付け、ファイルが `attachments/` に作成されることを確認する。vault直下に作成された場合は、保存先の指定を再確認する。

## Macでスクリーンショットを直接貼る

- 選択範囲をクリップボードへコピー：`Command + Control + Shift + 4`
- 画面全体をクリップボードへコピー：`Command + Control + Shift + 3`
- Obsidianへ貼り付け：`Command + V`

`Control` を付けない場合、画像はクリップボードではなくデスクトップへ保存される。

## ノートへの埋め込み

Obsidianへ画像を貼り付けると、ノートには次のような埋め込みリンクが挿入される。

```markdown
![[アルファベータ枝刈り_アルファカット.png]]
```

表示幅を指定する場合は、ファイル名の後ろにピクセル数を加える。

```markdown
![[アルファベータ枝刈り_アルファカット.png|600]]
```

貼り付け直後に、内容が分かる名前へ変更する。

```markdown
![[翼構造_桁接合部.png|600]]
```

Obsidianのファイル一覧上で画像を改名すれば、`内部リンクを常に更新する` が有効な場合はノート側のリンクも更新される。

## 画像ファイルの命名

基本形は `主題_内容` とする。ファイル名だけで画像の内容を推測できる名前を付ける。

```text
アルファベータ枝刈り_アルファカット.png
翼構造_桁接合部.jpg
```

- 日本語または一般的な英数字を使い、単語の区切りは `_` とする。
- 空白、`Pasted image ...`、`Screenshot ...` のまま残さない。
- 知識を説明する画像には日付を付けない。
- 実験結果や作業記録など、撮影日・作成日の識別が必要な画像は `YYYYMMDD_主題_内容` とする。
- 同じ主題・内容の画像が複数ある場合は、末尾に `_01`、`_02` を付ける。
- 拡張子は元の形式を維持し、小文字の `.png`、`.jpg`、`.webp` などを使う。
- 画像を改名するときはObsidianのファイル一覧から行い、参照リンクも更新されたことを確認する。

## 貼り付け後の確認

- 閲覧ビューで画像が表示されるか確認する。
- 画像リンクをクリックし、`attachments/` 内の画像が開くか確認する。
- ソースモードで、リンクの先頭が埋め込み記号付きの `![[...]]` になっているか確認する。
- 同名画像を作らない。必要に応じて内容が分かる名前へ変更する。
- 不要になった画像を削除する前に、バックリンクや全文検索で他のノートから参照されていないか確認する。

## 公開時の注意

- `20_Areas/` の公開ノートが参照する画像は、対応形式であれば公開物へコピーされる。
- 顔、氏名、住所、学生証、通知、位置情報、未公開研究、課題解答が写っていないか確認する。
- 第三者が作成した写真・図表は、公開権限を確認する。
- 公開できない画像を含むAreasノートには `publish: false` を付ける。
