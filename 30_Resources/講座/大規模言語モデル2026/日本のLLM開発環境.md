### モデル開発の推移

| 年 | 規模感 | 主なモデル |

**SLM（Small Language Model）への潮流**
- 背景①：小さいモデルでも、より多くのデータで長く学習すれば高性能に到達できる
- 背景②：推論コスト（運用コスト）まで含めると小さいモデルの費用対効果が高い

**Chinchilla Trap（"Go smol or go home"）**
- Chinchilla則は「訓練計算量が最小になるNとDの比」を与えるが、推論コストを一切考慮していない
- 最適モデルサイズの40〜60%のサイズを選び、訓練計算量を10〜42%追加すれば同性能に到達
- 訓練は一度、推論は無限回 → 小さいモデルを長く学習させる方が得

### 日本モデルの2分類

| | フルスクラッチ | 英語モデルからの継続事前学習 |

### モデルの大規模化の潮流

- 2018 GPT-1 (117M) → 2019 GPT-2 (1.5B) → 2020 GPT-3 (175B) → 2023 GPT-4（非公開）
- 構造は2017年のTransformerのまま、スケールだけ変えた
- GPT-4以降、フロンティアモデルはパラメータ数を非公開

**「知識量からパラメータ数を逆算」する推定手法（_Incompressible Knowledge Probes_）**
1. パラメータ数既知のオープンモデル（89個）で事実知識クイズ（IKP Score）を測定
2. `正答率 ∝ log₁₀(パラメータ数)` で回帰（R² = 0.917）
3. クローズドモデルの正答率を測り、回帰直線に外挿

| モデル | 点推定 | 90%予測区間 |
|---|---|---|
| GPT-5.5 | 〜9.7T | 3.2T – 28.7T |
| Claude Opus 4.6 | 〜5.3T | 1.8T – 15.6T |

- 区間が上下1桁ずつ開いている → 「9.7T」は「3兆かもしれないし29兆かもしれない」という意味
- 落とし穴①：MoEの場合、推論コストに効くのは活性パラメータ（総パラメータとは別物）
- 落とし穴②：正答率は学習データ質・量、事後学習、思考モードにも強く依存する
- 数字そのものより「そう推定するしかないほどブラックボックス化した」という事実のほうが情報量が大きい

### モデル構造の動向

**収束しつつある7つの設計**

| 設計 | 理由 |
|---|---|
| **pre-norm** | LayerNorm を残差ブロックの前に置く。勾配が深いモデルでも安定する（post-normはwarmup必須で壊れやすい） |
| **RMSNorm** | $\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum x_i^2}} \cdot g$。平均計算を省いて速い |
| **bias 項の全削除** | 効果がほぼゼロ。学習を不安定にすることがあり、パラメータも減る |
| **SwiGLU / GeGLU** | $\text{SwiGLU}(x) = (\text{Swish}(xW_1) \odot xW_2)W_3$。隠れ次元を2/3に調整。素のReLU FFNより一貫して強い |
| **RoPE** | 位置を回転行列としてQ・Kに掛ける。内積が相対位置 $(m-n)$ だけの関数 → 学習長を超えた外挿もしやすい |
| **GQA** | 複数のQuery headでK,Vを共有。KVキャッシュを1/8などに削減 → メモリ帯域律速な推論の高速化 |
| **局所+グローバルattentionの交互配置** | 多くの層はスライディングウィンドウで十分。数層に1回だけ全体を見る → 長文コンテキストのコストを大幅削減 |

- これらはすべて「性能を落とさずに速く・安定させる」工学的最適化 → **アーキテクチャの探索はほぼ終わり、勝負はデータと事後学習に移った**

**ハイブリッドアーキテクチャ（Qwen3.5、Nemotron 3）**

| 機構 | 計算量 | 状態サイズ | 特徴 |
|---|---|---|---|
| Attention | $O(L^2)$ | $O(L)$（KVキャッシュ） | 全過去を厳密に参照できる |
| SSM / 畳み込み系 | $O(L)$ | 固定 | 過去を圧縮して持つ。特定固有名詞のコピーが苦手 |

- 1:7くらいの比率でattention層を混ぜる → 精度を保ちつつ長文推論のメモリと速度が改善

**Claude Mythos 構造の仮説（第三者による外部推測）**

```
[通常]  X → Layer1 → Layer2 → Layer3 → Layer4 → Y   (4層ぶんの重み)
[再帰]  X → Layer1 ↺ ↺ → Layer3 ↺ ↺ → Y            (2層ぶんの重み、計算は同じ)
```

- 同じ層を複数回通す（recurrent depth / layer looping）
- 重みは共有 → パラメータは半分。推論時にループ回数を増やせば「重みを増やさずに考える深さだけ増やせる」
- 770M パラメータが 1.3B の Transformer に匹敵という報告あり
- **注：Anthropicの公式発表ではなく第三者の推測。`kyegomez/OpenMythos` は公式性・検証の質が玉石混交**
- 学ぶべき点：「再帰的深さ」という設計軸が推論能力を伸ばす有力候補として真剣に議論されていること

### 学習方法の進展

**SGS（Scaling Self-Play with Self-Guidance、Agrawal et al. 2025）**

- 問題意識：RLには「解けそうで解けない」問題が大量に要る。人間作成のデータセットは有限
- 解法：LLMに3役を担わせる自己対戦

| 役割 | 機能 |
|---|---|
| Proposer（出題者） | 新しい定理・命題を生成 |
| Guide（審査者） | ①ちょうどいい難易度か ②元の未解決問題と関連があるか を評価 |
| Solver（解答者） | 生成された問題をRLで解き、その経験で強くなる |

- Guide Scoreの高い「難しすぎず・関連がある」問題を選んでカリキュラムを自動生成 → 能力の境界が外側に広がる

| 手法 | 最終精度 |
|---|---|
| RL Baseline | 60.3%で漸近 |
| SGS | 67.1%、漸近が遅い |

- **「頭打ちの高さが変わっている」**：問題生成側にも学習を回すことでスケーリングの天井を上げられる
- IMO・ICPCの結果は「検証可能な報酬 × 自己生成カリキュラム」の系譜

- 総パラメータ700B、1トークンあたり活性化するのは40B
- 学習コスト・知識容量は700B相当、推論コストは40B相当
- 「日本のモデルは小さい」と単純に比較できない
